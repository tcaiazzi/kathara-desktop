# Security Policy

## Supported Versions

We release patches for security vulnerabilities only for the last version:

| Version | Supported          |
|---------|--------------------|
| 0.1.6   | :white_check_mark: |

## Reporting a Vulnerability

Please report (suspected) security vulnerabilities privately, by mail to
**[contact@kathara.org](mailto:contact@kathara.org)** — not in a public issue, where the details
would be visible to everyone before a fix is out. You will receive a response from us within 48
hours. If the issue is confirmed, we will release a patch as soon as possible.
